- Заказ через бот и через Mini App, запись в лист «Лист1».
- Заявки ателье и B2B из бота и Mini App.

## Известные проблемы (подробно: аудит 2026-11-25)

- P0: токен бота в истории публичных репозиториев; кабинет API без проверки `initData`; сумма заказа приходит из браузера; «подписка» включается без оплаты и без проверки срока.
- Расхождения цен (ИИ Mini App, `data.js`, сайт без «від», рушники за кг/шт).
- Распознавание заказа в боте ошибается с количеством («2 сорочки, джинси» → джинси × 2).
- Статусы, даты, номера заказов пишутся по-разному в боте и API.
- Патчи из аудитов 30.10–10.11 почти не внесены (внесён только шаг 1 из чата [Бот]).
